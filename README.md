# Mac mini M1 · Атлас конструкції D2.1

[Відкрити FDM-корпус у 3D](https://dvaderfun.github.io/mac-mini-m1-case-prototype/) · [плата розібраного Mac](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=board) · [дві зняті антени](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#antennas) · [дно й опори плати](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=base) · [задня панель](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=rear) · [живлення](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=power) · [PCB v1](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=pcb).

D2.1 — цифровий макет для холодної примірки на Ender 3 Pro. У пласкій задній панелі вісім окремих профільованих отворів; нижню крайку веде паз у дні, верхню утримує кришка. [Що змінилося на задньому куті](rear-comparison.jpg). Сім видів працюють також офлайн і на весь екран.

[Окрема 3D-модель плати Mac (GLB)](reference/mac-board-reference.glb) містить вузол без антен у базисі збірки. За фото уточнено гребінку радіатора й вигляд плати, позначено коаксіальні гнізда, дві втулки невідомої висоти та напрям виходу джгута. Зворот — із вихідної моделі. На сторінці дві зняті антени показано окремо; три сітки антен SnazzyLabs вмикаються лише для порівняння. Фізичні посадки, живлення, тепло й RF не прийняті.

[Завантажити STL і STEP](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#downloads) · [файли D2.1 у Git](downloads/d2.1/). Є п’ять STL корпуса, три зразки для примірки та два ZIP з інструкцією. Для CAD: [збірка з кріпленням і габаритами модулів](downloads/d2.1/d2-assembly.step) або [п’ять друкованих деталей](downloads/d2.1/d2-printable.step). Одиниці — мм.

Щоб отримати ці файли через Git:

~~~sh
git clone --depth 1 https://github.com/Dvaderfun/mac-mini-m1-case-prototype.git
cd mac-mini-m1-case-prototype/downloads/d2.1
~~~
