# Mac mini M1 · Атлас конструкції D2

[Відкрити FDM-корпус у 3D](https://dvaderfun.github.io/mac-mini-m1-case-prototype/) · [дно й опори плати](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=base) · [механізм задньої панелі](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=rear) · [тримач живлення](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=power) · [альтернативна PCB v1](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=pcb).

D2 — цифровий макет для холодної примірки на Ender 3 Pro. Штатна плата спирається на дно; задня панель висувається вбік зі знятою кришкою. Фізичні посадки, живлення, тепло й RF не прийняті. Шість видів працюють також офлайн та на весь екран.
