# Mac mini M1 · Атлас конструкції D2.3

[Відкрити корпус у 3D](https://dvaderfun.github.io/mac-mini-m1-case-prototype/) · [Як зібрати задню панель](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#assembly-guide) · [Посадка штекерів](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#port-fit) · [Схема для майстерні](rear-assembly.jpg) · [Боковий розріз HDMI та USB‑C](connector-section.svg).

Панель друкується зовнішньою стороною на столі. Опустіть її зверху в пази порожнього шасі; потім підведіть гнізда плати Mac до встановленої панелі й закріпіть плату. Установіть окремий вузол живлення та кришку. Для зняття панелі спочатку від'єднайте кабелі, зніміть кришку, звільніть кріплення й відведіть від отворів плату та PD IN.

[Пакети STL і два STEP](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#downloads) · [файли у Git](downloads/d2.3/) · [перша примірка](downloads/d2.3/d2.3-first-fit.zip) · [корпус](downloads/d2.3/d2.3-cold-fit-kit.zip) · [збірка STEP](downloads/d2.3/d23-assembly.step). Одиниці — мм. Беріть панель, дно, кришку і тримач однієї ревізії.

Оцінка власника для пластику оригінальної панелі перед роз’ємами — приблизно 1,5 мм. Це не замір осьового заглиблення кожного гнізда. Для D2.3 осьові відстані й контрольні габарити виведені з цифрової моделі. Своїми кабелями окремо перевірте посадку з панеллю і без неї, зазор під плечем, защіпання та звільнення RJ45. Друк і холодна примірка ще не прийняті.

Сім видів і повний екран: [плата Mac](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=board), [опори](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=base), [PD і Mini‑560](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=power), [альтернативна PCB v1](https://dvaderfun.github.io/mac-mini-m1-case-prototype/?view=pcb). [GLB плати без антен](reference/mac-board-reference.glb); [рисунки двох знятих антен](https://dvaderfun.github.io/mac-mini-m1-case-prototype/#antennas). Реальний джгут, висоти втулок, живлення, тепло та RF потребують окремих перевірок.
